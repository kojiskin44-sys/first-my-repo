# Student Funding Theme

学生の夢・社会活動・ビジネスアイデアを支援するクラウドファンディングサイト用WordPressテーマ

## 概要

このテーマは、学生が自分のプロジェクトを投稿し、支援者から寄付を集めることができるクラウドファンディングプラットフォームを構築するために設計されています。

## 主な機能

### カスタム投稿タイプ「project」
- プロジェクト名・画像
- ストーリー本文
- 学生プロフィール（名前・学校名・学年・写真）
- 目標金額・現在の支援額
- 支援締切日
- リターン情報

### 支援システム
- PayPal決済対応
- 銀行振込対応
- 会員登録なしでも支援可能
- 匿名支援オプション
- リターン辞退オプション
- 支援データの自動集計

### テンプレート
- `front-page.php` - トップページ（新着・注目プロジェクト）
- `archive-project.php` - プロジェクト一覧
- `single-project.php` - プロジェクト詳細・支援フォーム
- `page-support-complete.php` - 支援完了ページ
- `page-student-profile.php` - 学生プロフィールページ

### デザイン
- 白ベース、ブルー系アクセントカラー
- レスポンシブデザイン対応
- 余白を多く使ったシンプルなレイアウト
- 学生向けの親しみやすいUI

## インストール方法

1. このテーマフォルダをZIP化します
2. WordPressの管理画面から「外観」→「テーマ」→「新規追加」→「テーマのアップロード」
3. ZIPファイルを選択してアップロード
4. テーマを有効化

## 初期設定

### 1. パーマリンク設定
「設定」→「パーマリンク設定」で「投稿名」を選択して保存してください。

### 2. メニューの設定
「外観」→「メニュー」からプライマリーメニューとフッターメニューを設定できます。

### 3. 支援完了ページの作成
1. 「固定ページ」→「新規追加」
2. タイトルを「支援完了」とし、スラッグを「support-complete」に設定
3. テンプレートで「支援完了ページ」を選択
4. 公開

### 4. プロジェクトカテゴリーの追加
「プロジェクト」→「カテゴリー」から以下のようなカテゴリーを追加することをおすすめします：
- 社会活動
- ビジネス
- 夢の実現
- 学業

## 使い方

### プロジェクトの投稿
1. 「プロジェクト」→「新規追加」
2. プロジェクトタイトルと本文（ストーリー）を入力
3. アイキャッチ画像を設定
4. 「プロジェクト詳細」メタボックスで以下を入力：
   - 目標金額
   - 支援締切日
   - PayPalリンク（任意）
   - 銀行振込情報
   - リターン情報
5. 「学生プロフィール」メタボックスで学生情報を入力
6. カテゴリーを選択
7. 公開

### 支援データの管理
管理画面の「支援データ」メニューから、支援の一覧とステータス管理ができます。

ステータス：
- **保留中（pending）**: 支援申込みは完了、決済待ち
- **完了（completed）**: 決済完了、プロジェクトの支援額に反映
- **キャンセル（cancelled）**: キャンセルされた支援

## screenshot.pngについて

WordPressテーマには `screenshot.png` (1200x900px) が必要です。
以下のコマンドで作成できます（ImageMagickが必要）：

```bash
convert -size 1200x900 gradient:#667eea-#764ba2 \
  -gravity center -pointsize 72 -fill white \
  -annotate +0+0 "Student Funding Theme" \
  screenshot.png
```

または、任意の画像編集ソフトで1200x900pxの画像を作成し、`screenshot.png`として保存してください。

## カスタマイズ

### 色の変更
`assets/css/style.css` 内の以下の箇所を編集してください：
- プライマリーカラー: `#2196F3`
- グラデーション: `#667eea` → `#764ba2`

### PayPal設定
各プロジェクトの編集画面で「PayPalリンク」にPayPalの決済リンクを入力してください。

### 銀行振込情報
各プロジェクトの編集画面で「銀行振込情報」に振込先を入力してください。
