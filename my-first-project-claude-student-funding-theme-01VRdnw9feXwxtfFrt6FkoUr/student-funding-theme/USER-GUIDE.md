## 1. インストール方法

### 手順1: テーマのアップロード

1. **WordPressの管理画面にログイン**
   - ブラウザで `http://あなたのサイト.com/wp-admin` にアクセス
   - ユーザー名とパスワードを入力してログイン

2. **テーマのアップロード画面を開く**
   - 左側のメニューから「外観」をクリック
   - 「テーマ」をクリック
   - 画面上部の「新規追加」ボタンをクリック
   - 「テーマのアップロード」ボタンをクリック

3. **ZIPファイルをアップロード**
   - 「ファイルを選択」ボタンをクリック
   - `student-funding-theme.zip` を選択
   - 「今すぐインストール」をクリック

4. **テーマを有効化**
   - インストール完了後、「有効化」ボタンをクリック

### 手順2: パーマリンク設定（重要！）

1. 左側のメニューから「設定」→「パーマリンク設定」をクリック
2. 「投稿名」を選択
3. 画面下部の「変更を保存」をクリック

**注意:** この設定をしないと、プロジェクトページが正しく表示されません。

## 2. 初期設定

### 2-1. 支援完了ページの作成

支援が完了した後に表示されるページを作成します。

1. **固定ページを新規作成**
   - 左側のメニューから「固定ページ」→「新規追加」

2. **ページ情報を入力**
   - **タイトル:** 「支援完了」と入力
   - **本文:** 空欄でOK（自動で表示されます）

3. **スラッグを設定**
   - 右側の「パーマリンク」セクションを開く
   - 「URLスラッグ」に `support-complete` と入力（半角英数）

4. **テンプレートを選択**
   - 右側の「ページ属性」セクションを開く
   - 「テンプレート」から「支援完了ページ」を選択

5. **公開**
   - 「公開」ボタンをクリック

### 2-2. プロジェクトカテゴリーの作成

プロジェクトを分類するためのカテゴリーを作成します。

1. **カテゴリー管理画面を開く**
   - 左側のメニューから「プロジェクト」→「カテゴリー」

2. **おすすめのカテゴリー**
   以下のようなカテゴリーを作成することをおすすめします：

   | カテゴリー名 | スラッグ | 説明 |
   |------------|---------|-----|
   | 社会活動 | social | 社会貢献・ボランティア活動 |
   | ビジネス | business | 学生起業・ビジネスアイデア |
   | 夢の実現 | dream | 個人の夢や目標の達成 |
   | 学業 | study | 研究・留学・資格取得 |
   | クリエイティブ | creative | 芸術・音楽・映像制作 |

3. **カテゴリーの追加方法**
   - 「名前」にカテゴリー名を入力（例: 社会活動）
   - 「スラッグ」に半角英数字を入力（例: social）
   - 「説明」に簡単な説明を入力
   - 「新規カテゴリーを追加」ボタンをクリック

### 2-3. メニューの設定

サイトのナビゲーションメニューを設定します。

1. **メニュー管理画面を開く**
   - 左側のメニューから「外観」→「メニュー」

2. **新しいメニューを作成**
   - 「新しいメニューを作成しましょう」をクリック
   - メニュー名を入力（例: プライマリーメニュー）
   - 「メニューを作成」をクリック

3. **メニュー項目を追加**
   - 左側の「カスタムリンク」を開く
   - おすすめのメニュー項目：

   ```
   URL: /project/
   リンクテキスト: プロジェクト一覧

   URL: #about
   リンクテキスト: サイトについて

   URL: #howto
   リンクテキスト: 使い方
   ```

4. **メニューの位置を設定**
   - 「プライマリーメニュー」にチェック
   - 「メニューを保存」をクリック

### 2-4. サイトのロゴ設定（オプション）

1. 左側のメニューから「外観」→「カスタマイズ」
2. 「サイト基本情報」をクリック
3. 「ロゴを選択」からロゴ画像をアップロード
4. 「公開」をクリック

## 3. プロジェクトの投稿方法

### ステップ1: 新規プロジェクトの作成

1. **プロジェクト作成画面を開く**
   - 左側のメニューから「プロジェクト」→「新規追加」

### ステップ2: 基本情報の入力

2. **プロジェクトタイトルを入力**
   - 画面上部の「タイトルを追加」欄に魅力的なタイトルを入力
   - 例: 「途上国の子どもたちに教育を届けたい！」

3. **プロジェクトのストーリーを書く**
   - エディタにプロジェクトの詳細を記入
   - 以下の内容を含めると良いでしょう：
     - **背景:** なぜこのプロジェクトを始めたのか
     - **目的:** 何を達成したいのか
     - **活動内容:** 具体的に何をするのか
     - **資金の使い道:** 集めたお金をどう使うのか
     - **期待される効果:** このプロジェクトの成果

### ステップ3: プロジェクト詳細の設定

画面を下にスクロールすると「プロジェクト詳細」のボックスがあります。

4. **目標金額を入力**
   - 例: 100000（10万円の場合）
   - 半角数字で入力してください

5. **支援締切日を設定**
   - カレンダーから日付を選択
   - 例: 2025-03-31

6. **PayPalリンクを入力（オプション）**
   - PayPal決済を利用する場合のみ入力
   - PayPalの管理画面で作成した支払いリンクを貼り付け
   - 例: `https://www.paypal.me/yourname`

7. **銀行振込情報を入力**
   ```
   銀行名: ○○銀行
   支店名: △△支店
   口座種別: 普通
   口座番号: 1234567
   口座名義: ガクセイ タロウ
   ```

8. **リターン情報を記入（オプション）**
   ```
   【1,000円】
   ・お礼のメッセージをメールでお送りします

   【5,000円】
   ・活動報告書をPDFでお送りします
   ・お礼のメッセージ

   【10,000円以上】
   ・活動報告書（冊子版）を郵送
   ・現地の写真データ
   ・お礼のメッセージ

   ※すべてのリターンは辞退することもできます
   ```

### ステップ4: 学生プロフィールの入力

画面を下にスクロールすると「学生プロフィール」のボックスがあります。

9. **学生情報を入力**
   - **学生名:** 山田 太郎
   - **学校名:** ○○大学
   - **学年:** 3年生

10. **学生写真をアップロード**
    - 「写真を選択」ボタンをクリック
    - 画像を選択またはアップロード
    - 「写真を選択」ボタンをクリック
    - 顔写真または活動中の写真がおすすめです

### ステップ5: アイキャッチ画像の設定

11. **メイン画像を設定**
    - 右側のサイドバーの「アイキャッチ画像」をクリック
    - 「アイキャッチ画像を設定」をクリック
    - プロジェクトを象徴する魅力的な画像を選択
    - 推奨サイズ: 1200 x 800 ピクセル以上

### ステップ6: カテゴリーの選択

12. **プロジェクトのカテゴリーを選択**
    - 右側のサイドバーの「プロジェクトカテゴリー」から該当するものを選択
    - 複数選択可能

### ステップ7: 公開

13. **プレビューで確認（推奨）**
    - 右上の「プレビュー」ボタンをクリック
    - 表示を確認

14. **公開**
    - 問題なければ「公開」ボタンをクリック
    - これでプロジェクトが公開されました！

## 4. 支援の流れ

### 支援者側の操作

1. **プロジェクトを探す**
   - トップページまたは「プロジェクト一覧」から興味のあるプロジェクトをクリック

2. **プロジェクト詳細を確認**
   - ストーリー、目標金額、学生プロフィールなどを確認

3. **支援ボタンをクリック**
   - 右側の「このプロジェクトを支援する」ボタンをクリック
   - モーダルウィンドウ（ポップアップ）が開きます

4. **支援フォームに入力**

   **必須項目:**
   - **支援額:** 100円以上を入力（例: 3000）
   - **メールアドレス:** 確認メールが届くアドレス
   - **決済方法:** PayPalまたは銀行振込を選択

   **任意項目:**
   - **お名前:** ニックネーム可（空欄の場合は「匿名」として表示）
   - **匿名で支援する:** チェックすると名前が表示されません
   - **リターンを辞退する:** チェックするとリターン不要を選択できます
   - **応援メッセージ:** 学生へのメッセージ（非公開）

5. **支援を確定**
   - 「支援を確定する」ボタンをクリック

6. **決済方法に応じた処理**

   **PayPalを選択した場合:**
   - PayPalの決済ページに自動で移動します
   - PayPalアカウントまたはクレジットカードで決済

   **銀行振込を選択した場合:**
   - 支援完了ページに振込先情報が表示されます
   - 表示された口座に振込を行ってください
   - 確認メールにも振込先情報が記載されています

7. **支援完了！**
   - 支援完了ページで内容を確認
   - メールでも確認メールが届きます

## 5. 支援データの管理

### 5-1. 支援データの確認

1. **支援データ管理画面を開く**
   - 左側のメニューから「支援データ」をクリック

2. **表示される情報**
   - ID: 支援データの識別番号
   - プロジェクト: 支援されたプロジェクト名
   - 支援者名: 支援者の名前（匿名の場合は「匿名」）
   - メールアドレス: 支援者の連絡先
   - 支援額: 支援金額
   - 決済方法: PayPalまたは銀行振込
   - 日時: 支援申込み日時
   - ステータス: 現在の状態
   - 操作: ステータス変更

### 5-2. ステータスの種類

| ステータス | 意味 | 対応 |
|-----------|------|------|
| 保留中 (pending) | 支援申込み完了、決済待ち | 決済確認後に「完了」に変更 |
| 完了 (completed) | 決済完了、支援額に反映済み | 特になし |
| キャンセル (cancelled) | キャンセルされた支援 | 支援額から除外 |

### 5-3. ステータスの変更方法

1. **銀行振込の場合の処理**
   - 支援者から振込があったら、通帳やオンラインバンキングで確認
   - 該当の支援データのステータスを「保留中」→「完了」に変更
   - ドロップダウンから「完了」を選択し、「更新」ボタンをクリック

2. **自動更新について**
   - ステータスを「完了」に変更すると、プロジェクトの支援額と支援者数が自動的に更新されます
   - フロント画面の進捗バーも自動で更新されます

### 5-4. 支援者への連絡

支援者のメールアドレスは管理画面で確認できます。
必要に応じて以下のタイミングで連絡を取りましょう：

- 振込確認のお礼
- プロジェクト進捗報告
- リターンの発送通知
- プロジェクト完了報告

## 6. よくある質問

### Q1. プロジェクトが表示されない

**A:** パーマリンク設定を確認してください。
1. 「設定」→「パーマリンク設定」
2. 「投稿名」を選択
3. 「変更を保存」をクリック

### Q2. 支援額が更新されない

**A:** 支援データのステータスを確認してください。
- ステータスが「完了」の支援のみが集計されます
- 「保留中」のステータスを「完了」に変更してください

### Q3. PayPalリンクの取得方法は？

**A:** PayPal.Meリンクを使うのが簡単です。
1. PayPalアカウントにログイン
2. 「PayPal.Me」ページを作成
3. 表示されたリンク（例: https://www.paypal.me/yourname）をコピー
4. プロジェクト編集画面の「PayPalリンク」に貼り付け

### Q4. アイキャッチ画像のサイズは？

**A:** 推奨サイズは 1200 x 800 ピクセル以上です。
- 横長の画像がきれいに表示されます
- ファイルサイズは1MB以下を推奨

### Q5. 締切日を過ぎたらどうなる？

**A:** 自動で以下のように表示されます。
- プロジェクトカードに「終了」バッジが表示
- プロジェクト詳細ページで「終了」と表示
- 支援ボタンが無効化される

### Q6. 支援者を匿名にできる？

**A:** はい、できます。
- 支援フォームで「匿名で支援する」にチェック
- または、お名前欄を空欄にする
- 支援者一覧には「匿名」と表示されます

### Q7. リターンは必須？

**A:** いいえ、任意です。
- 支援者は「リターンを辞退する」を選択できます
- リターンなしのプロジェクトも作成可能

### Q8. 複数のプロジェクトを作成できる？

**A:** はい、無制限に作成できます。
- 同じ学生が複数のプロジェクトを投稿できます
- プロジェクトごとに支援データが管理されます

## 7. トラブルシューティング

### 問題: 支援フォームが送信できない

**原因と対策:**

1. **JavaScriptエラー**
   - ブラウザのコンソールでエラーを確認
   - 他のプラグインと競合している可能性
   - 一時的に他のプラグインを無効化して確認

2. **バリデーションエラー**
   - 支援額が100円以上か確認
   - メールアドレスの形式が正しいか確認
   - 決済方法を選択しているか確認

3. **AJAX通信エラー**
   - サーバーの通信状態を確認
   - WordPressのデバッグモードを有効化して確認

### 問題: 画像が表示されない

**原因と対策:**

1. **画像のアップロード失敗**
   - ファイルサイズが大きすぎる可能性
   - php.iniの`upload_max_filesize`を確認

2. **パーミッションエラー**
   - uploadsディレクトリの書き込み権限を確認
   - 権限を755または777に設定

### 問題: データベーステーブルが作成されない

**原因と対策:**

1. テーマを一度無効化して再度有効化
2. functions.phpの`student_funding_create_support_table()`を確認
3. データベースの権限を確認

### 問題: メールが届かない

**原因と対策:**

1. **SMTPの設定**
   - WP Mail SMTPなどのプラグインを使用
   - 送信サーバーを正しく設定

2. **迷惑メールフォルダ**
   - 迷惑メールフォルダを確認
